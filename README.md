# Task Manager (To-Do App with localStorage)

A fully functional task management application built using HTML, CSS, and Vanilla JavaScript.  
This project demonstrates CRUD operations, state management, and modular JavaScript architecture using browser localStorage.

---

## 🔥 Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks (All / Completed / Pending)
- Persistent storage using localStorage
- Dynamic UI rendering

---

## 🧠 Key Concepts Used

- CRUD operations (Create, Read, Update, Delete)
- DOM manipulation
- Event handling
- localStorage for persistence
- Modular JavaScript structure
- Separation of concerns (UI, logic, storage, tasks)

---

## 🏗️ Project Structure

- `index.html` → Main UI structure  
- `css/style.css` → Styling  
- `js/app.js` → Core application logic  
- `js/storage.js` → localStorage handling  
- `js/ui.js` → UI rendering and DOM updates  
- `js/tasks.js` → task related logic here   

---

## 🔄 Application Flow

User Action → App Logic → Storage Update → UI Re-render

---

## ⚙️ How to Run

1. Clone the repository
2. Open `index.html` in your browser
3. Start adding tasks

No additional setup required.
